## Descricao

Como coordenador de producao, preciso de endpoints para criar e gerenciar Ordens de Producao (OPs) e seus sub-lotes, com geracao automatica de barcodes e calculo de quantidades via query (sem campos desnormalizados).

## Criterios de Aceitacao

- [x] **AC1:** Endpoint `POST /api/production/orders` cria OP com dados obrigatorios (referencia, quantidade, meta_coefficient)
- [x] **AC2:** `meta_coefficient` copiado de `reference_targets` como snapshot na criacao da OP
- [x] **AC3:** Endpoint `GET /api/production/orders` lista OPs do tenant com paginacao
- [x] **AC4:** Endpoint `GET /api/production/orders/:id` retorna OP com lotes e quantidades computadas
- [x] **AC5:** Quantidades (`produced`, `stocked`, `defect`, `discarded`) computadas via query sobre `scan_events`/`defect_records` — NAO lidas de campos da tabela
- [x] **AC6:** Endpoint `POST /api/production/orders/:id/lots` cria sub-lotes com barcode gerado automaticamente
- [x] **AC7:** Barcode gerado no formato `OP-{op_number}-{seq}-L{lot_seq}` validado pela constraint
- [x] **AC8:** Endpoint `GET /api/production/lots/:id` retorna lote com historico de scans
- [x] **AC9:** Todas as queries via Supabase client autenticado

## Escopo

**IN:**
- CRUD de Ordens de Producao
- Criacao de sub-lotes com barcode automatico
- Consulta de lote com historico
- Calculo de quantidades via query (Opcao A — Item 5 v2.1)
- Snapshot de meta_coefficient (Item 13 v2.1)

**OUT:**
- Edicao/exclusao de OP (apenas criacao na Fase 1)
- Gestao de estagios (pre-configurados no seed)
- Relatorios de producao (Fase 2)
- Faccoes e aduana (Fase 2)

## Notas Tecnicas

- **Item 5 (v2.1) — Opcao A:** Quantidades SEMPRE computadas via query. Exemplo:
  ```sql
  SELECT COUNT(*) as produced_quantity
  FROM scan_events se
  JOIN lots l ON l.id = se.lot_id
  WHERE l.po_id = :poId AND se.stage_id = :finalStageId
  ```
- **Item 13 (v2.1):** Na criacao da OP, fazer `SELECT meta_coefficient FROM reference_targets WHERE ...` e copiar para `production_orders.meta_coefficient`
- **Barcode format (Item 12):** `OP-{YYYYMMDD}-{seq}-L{lot_seq}`. O `op_number` segue formato proprio e e unico por tenant.
- **Paginacao:** Usar `range()` do Supabase client para paginacao offset-based
- **Source:** `docs/architecture/ARCHITECTURE-REVIEW-v2.1.md` items 5, 12, 13
