## Descricao

Como faccao, preciso de uma interface mobile-first para acessar o portal via celular, com tela de login (token + PIN), layout simplificado com navegacao bottom tabs, e 6 telas de conteudo: inicio (resumo), lotes, devolucoes, defeitos, financeiro e notificacoes.

## Criterios de Aceitacao

- [ ] **AC1:** Route group `(portal)` criado em `src/app/(portal)/` com layout proprio (sem sidebar da Liserie)
- [ ] **AC2:** Tela de login em `/portal` aceita token (via URL param) e PIN (input), chama POST /api/faction/auth/login
- [ ] **AC3:** Layout autenticado com navegacao bottom tabs (mobile-first)
- [ ] **AC4:** Tela 1 — Inicio (`/portal/`): resumo com numeros grandes (pecas, prazo, valor), glanceable em 5 segundos
- [ ] **AC5:** Tela 2 — Lotes (`/portal/shipments`): lista de lotes com status (verde/amarelo/vermelho) + detalhe (`/portal/shipments/[id]`)
- [ ] **AC6:** Tela 3 — Devolucoes (`/portal/returns`): pendentes por urgencia, com acao de informar previsao
- [ ] **AC7:** Tela 4 — Defeitos (`/portal/defects`): lista com opcao de confirmar ou contestar
- [ ] **AC8:** Tela 5 — Financeiro (`/portal/financial`): periodo aberto + historico
- [ ] **AC9:** Tela 6 — Notificacoes (`/portal/notifications`): lista com badge de nao-lidas
- [ ] **AC10:** Design system OKLCH monochrome identico ao LISION
- [ ] **AC11:** Indicadores visuais de status: verde (OK), amarelo (atencao), vermelho (critico)
- [ ] **AC12:** Responsivo — funciona em telas de 320px a 768px

## Notas Tecnicas

- **Layout group:** `src/app/(portal)/` — completamente separado do `(app)/`. Sem sidebar, sem header da Liserie.
- **Bottom tabs:** 4-5 icones na base: Inicio, Lotes, Devolucoes, Defeitos, Mais (financial + notifications)
- **Token via URL:** `/portal?token=<uuid>` — extrair token do query param e pre-preencher
- **Design system:** Reusar componentes shadcn/ui existentes, paleta OKLCH monochrome
- **Status indicators:** Badge com cor: `bg-emerald-500` (OK), `bg-amber-500` (atencao), `bg-red-500` (critico)
- **Numeros grandes:** Tela 1 usa `text-4xl font-bold` para KPIs
- **Contestacao inline:** Na tela de defeitos, botao "Contestar" abre modal com textarea para motivo
- **Reagendamento:** Na tela de devolucoes, date picker para nova data (desabilitado se reschedule_count >= 2)
- **Source:** `docs/architecture/FACTION-PORTAL-ARCHITECTURE.md` secao 7
- **UX Reference:** `docs/ux/LISION-UX-UI-SPEC.md`
