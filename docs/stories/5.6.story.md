## Descricao

Como coordenador de producao, preciso gerar etiquetas com barcode para colar nos lotes fisicos, permitindo a bipagem com scanner USB. O endpoint deve gerar ZPL (Zebra Programming Language) para impressora Zebra GC420t e PDF como fallback.

## Criterios de Aceitacao

- [ ] **AC1:** Endpoint `POST /api/print/label` recebe `{ lot_ids: string[] }` e retorna ZPL
- [ ] **AC2:** ZPL gerado contendo: barcode Code128, OP number, lote sequencial, referencia do produto
- [ ] **AC3:** Fallback: parametro `?format=pdf` retorna PDF com barcodes ao inves de ZPL
- [ ] **AC4:** Maximo 50 etiquetas por requisicao
- [ ] **AC5:** Validacao: todos os lot_ids devem pertencer ao tenant do usuario autenticado
- [ ] **AC6:** Endpoint protegido por auth middleware

## Escopo

**IN:**
- Geracao de ZPL para impressora Zebra
- Geracao de PDF como fallback
- Validacao de lotes por tenant

**OUT:**
- Comunicacao direta com a impressora (frontend envia ZPL via browser print)
- Configuracao de impressora
- Design customizado de etiquetas (formato fixo na Fase 1)

## Notas Tecnicas

- **ZPL:** Zebra GC420t aceita comandos ZPL via raw print. Frontend envia o ZPL recebido para a impressora via `window.print()` ou driver raw.
- **PDF fallback:** Usar biblioteca leve como `jspdf` ou `@react-pdf/renderer` server-side para gerar PDF com barcodes.
- **Code128:** Barcode linear padrao industrial, legivel por scanners USB comuns.
- **Formato da etiqueta:** Barcode + texto legivel humano (OP, lote, referencia) em etiqueta 50x25mm.
