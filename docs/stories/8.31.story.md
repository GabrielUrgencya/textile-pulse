## Descrição

A tela de TV (modo display) não tem fullscreen — a interface do navegador (barra de endereço, abas) fica visível, prejudicando a exibição em TV/monitor dedicado. Adicionar um botão **Fullscreen** usando a Fullscreen API.

## Critérios de Aceitação

- [x] **AC1:** **Given** a tela de TV, **When** exibida, **Then** há um **botão Fullscreen** visível (canto superior direito).
- [x] **AC2:** **Given** o botão, **When** clicado, **Then** a interface ocupa 100% da tela via `document.documentElement.requestFullscreen()`.
- [x] **AC3:** **Given** o modo fullscreen, **When** o usuário pressiona **ESC** ou clica novamente no botão, **Then** sai do fullscreen (`document.exitFullscreen()`).
- [x] **AC4:** **Given** Chrome e Edge (navegadores comuns em TV sticks), **When** usado, **Then** funciona (usar a API padrão; opcionalmente prefixos webkit como fallback).
- [x] **AC5:** **Given** o modo fullscreen, **When** ocioso por **3s**, **Then** o botão **desaparece**; ao mover o cursor/tocar a tela, **reaparece**.
- [x] **AC6:** **Given** o estado de fullscreen muda por fora (ex.: ESC do browser), **When** isso ocorre, **Then** o ícone do botão reflete o estado correto (listener de `fullscreenchange`).
- [x] **AC7:** `lint`, `tsc`, `build` passam.

## Escopo

**IN:**
- `src/app/(kiosk)/tv/page.tsx` e/ou `src/components/tv/TVHeader.tsx` — botão Fullscreen + lógica de toggle + auto-hide.

**OUT:**
- Forçar fullscreen automático ao abrir (browsers bloqueiam sem gesto do usuário).
- Mudanças no conteúdo/KPIs da TV.

## Notas Técnicas
- Componente client (`"use client"`); usar `useState` para `isFullscreen` e `useEffect` para o listener `fullscreenchange` (com cleanup).
- Auto-hide: `setTimeout` rearmado em `mousemove`/`touchstart`; só esconder quando em fullscreen.
- Fallback opcional: `webkitRequestFullscreen` / `webkitExitFullscreen` para compatibilidade.
- Acessibilidade: `aria-label` no botão ("Tela cheia"/"Sair da tela cheia").
