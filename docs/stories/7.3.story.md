## Descricao

Como dono da Liserie, preciso que a TV mostre periodicamente um ranking gamificado das Top 3 faccoes em performance (pontualidade, qualidade, volume), com uma transicao cinematografica tipo Copa do Mundo, para gerar competicao saudavel, reconhecimento publico e transparencia entre as faccoes. O overlay aparece a cada 2 minutos por 15 segundos com transicao "bumper LISION" — cortina, logo hit com flash, revelacao do podium.

## Criterios de Aceitacao

- [ ] **AC1:** Overlay aparece automaticamente a cada 120 segundos
- [ ] **AC2:** Transicao de entrada: cortina (clipPath wipe 0-0.8s), logo hit com flash brightness (0.8-1.5s), revelacao do podium staggered 2o→3o→1o (1.5-2.5s)
- [ ] **AC3:** Podium exibe 3 faccoes com: avatar (iniciais ou foto), nome, score composto, posicao visual em podium (1o centro mais alto, 2o esquerda, 3o direita)
- [ ] **AC4:** Breakdown de score do 1o lugar exibido abaixo: Pontualidade, Qualidade, Volume com mini progress bars
- [ ] **AC5:** Transicao de saida: fade + scale down (0.5s), linha recolhe (0.4s), cortina reversa (0.7s)
- [ ] **AC6:** Duracao total do overlay: 15 segundos (2.5s entrada + 10s exibicao + 2.5s saida)
- [ ] **AC7:** Dashboard continua atualizando por tras durante o overlay — sem perda de dados

## Notas Tecnicas

- **Ref UX completa:** `docs/ux/TV-DASHBOARD-UX-SPEC.md` secao "RANKING DE FACCOES (Overlay Cinematografico)"
- **Ref arquitetura:** `C:\Users\Gabriel\.claude\plans\parsed-stirring-aurora.md` secao "RANKING DE FACÇÕES — Podium Gamificado"
- **State Machine do overlay:**
  ```
  IDLE (dashboard) → ENTERING (2.5s) → SHOWING (10s) → EXITING (2s) → IDLE
           ↑                                                    │
           └────────────────────────────────────────────────────┘
                          ciclo a cada 120s
  ```
- **Framer Motion:** Usar `AnimatePresence` para controlar entrada/saida. `clipPath`, `filter`, `letterSpacing`, `scale`, `opacity` sao props animaveis nativas do motion v12
- **Cortina:** `clipPath: "inset(50% 0 50% 0)"` → `"inset(0% 0 0% 0)"` — laminas expandem do centro
- **Logo hit:** `filter: "brightness(2)"` → `"brightness(1)"` — flash branco que dissipa
- **Titulo:** `letterSpacing: "0.5em"` → `"0.18em"` — compressao dramatica
- **Podium stagger:** 2o (delay 1.8s) → 3o (delay 2.0s) → 1o (delay 2.3s com scale 0.5→1)
- **Cores podium:** `border-warning` (dourado/ouro), `border-muted-foreground/60` (prata), `border-warning/40` (bronze) — tokens existentes
- **Avatar:** Se `avatar_url` existe, mostrar imagem. Se nao, mostrar iniciais em circulo colorido
- **Breakdown bars:** 3 mini progress bars com labels PONTUALIDADE, QUALIDADE, VOLUME
- **Skip condition:** Se `faction_ranking.length < 1`, nao mostrar overlay

### Frame Timing Detalhado

| Frame | Tempo | Efeito |
|---|---|---|
| Cortina abre | 0-800ms | `clipPath` inset 50%→0% |
| Logo aparece | 800-1300ms | scale 0.8→1, brightness 2→1 |
| Linha expande | 1000-1500ms | width 0→280px |
| Titulo comprime | 1100-1700ms | letterSpacing 0.5em→0.18em |
| Logo sobe | 1500-2100ms | y→-120, opacity→0.6, scale→0.7 |
| Podium container | 1700-2500ms | opacity 0→1, y 40→0 |
| 2o lugar | 1800ms delay | scale/opacity in |
| 3o lugar | 2000ms delay | scale/opacity in |
| 1o lugar | 2300ms delay | scale 0.5→1 (dramatico) |
| Exibicao | 2500-12500ms | Podium estatico visivel |
| Content fade | 12500-13000ms | opacity→0, scale→0.95 |
| Linha recolhe | 12700-13100ms | width→0 |
| Cortina fecha | 13000-13700ms | clipPath 0%→50% |
| Cleanup | 14000ms | Remove overlay do DOM |
