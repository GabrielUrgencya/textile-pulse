## Descrição

O `GoalsRow` do Dashboard usa **sempre** `targets.dailyPiecesTarget` como alvo de pontos, independentemente do toggle. Como só existe meta diária, alternar para Semana/Mês muda apenas o **intervalo** (acumula mais pontos) mas o **alvo continua 180**. É preciso **metas independentes** por período.

## Critérios de Aceitação

- [x] **AC1:** **Given** a tela de Configurações → Metas, **When** a Érica abre, **Then** há **3 campos separados**: Meta Diária, Meta Semanal e Meta Mensal (pontos), com valores **independentes** (não múltiplos da diária).
- [x] **AC2:** **Given** os 3 campos, **When** ela salva, **Then** `dailyPiecesTarget`, `weeklyPointsTarget` e `monthlyPointsTarget` persistem em `tenant.settings` (JSON).
- [x] **AC3:** **Given** o toggle do Dashboard em **Hoje**, **Then** o card "Pontos de Meta" usa a **meta diária**.
- [x] **AC4:** **Given** o toggle em **Semana**, **Then** usa a **meta semanal**; em **Mês**, usa a **meta mensal**.
- [x] **AC5:** **Given** metas semanal/mensal não cadastradas, **When** exibidas, **Then** usa um default sensato (ex.: 0 ou vazio com aviso) sem quebrar o cálculo de %.
- [x] **AC6:** `lint`, `tsc`, `build` passam.

## Escopo

**IN:**
- `src/app/api/settings/targets/route.ts` — GET retorna `weeklyPointsTarget` e `monthlyPointsTarget`; PATCH salva os 3.
- Tela de Configurações (metas) — 3 campos separados.
- `src/hooks/use-dashboard-data.ts` (`Targets`) — incluir os novos campos.
- `src/components/dashboard/Dashboard.tsx` (`GoalsRow`) — escolher o alvo de pontos pelo período (today/week/month).

**OUT:**
- Migração de banco (usa `tenant.settings` JSON).
- Metas semanais/mensais para lotes/OPs (apenas pontos de meta nesta story).

## Notas Técnicas
- O período é conhecido no `Dashboard` (`period`); passar para `GoalsRow` (hoje recebe só `kpis`/`targets`) para selecionar o alvo.
- `tenant.settings` já possui chaves legadas `weekly_target`/`monthly_target` no default — padronizar para `weeklyPointsTarget`/`monthlyPointsTarget` (camelCase, como os demais targets) para consistência com a API.
- Cálculo de %/projeção: aplicar o alvo do período; a projeção de turno só faz sentido em "Hoje" (manter como está para today, ocultar/ajustar nos demais).
