## Descrição

Camada de dados/contrato para o sistema de **KPIs configuráveis por setor**. A tabela `sector_dashboard_configs` (layout JSONB de widgets, 1 por `tenant×stage`) já foi aplicada pela Dara. Esta story cria os **tipos TypeScript**, o **helper de leitura com fallback para layout default** e a **API GET/PUT** que a TV (8.40) e o builder (8.41) consomem.

> Setor = `Stage`. Sem cores novas. O `layout` é um array de `KPIWidget` validado na app (união TS).

## Critérios de Aceitação

### A — Tipos e contrato
- [x] **AC1:** **Given** o épico, **When** os tipos são criados, **Then** existe `src/lib/dashboard-config.ts` com `KPIWidget` (`id`, `type: 'counter'|'progress'|'chart'|'ranking'|'timer'|'status'|'comparison'`, `metric`, `label`, `size: 'sm'|'md'|'lg'|'xl'`, `position: {x,y}`, `thresholds?: {warning,critical}`) e `SectorDashboardConfig` (`sectorId`, `layout: KPIWidget[]`, `updatedAt`, `updatedBy`).
- [x] **AC2:** **Given** os tipos, **When** um setor não tem config salva, **Then** há um **layout DEFAULT** (constante) que cobre as métricas já existentes (meta do momento, distância, tempo de processo, status facção) — a TV nunca fica vazia.

### B — Helper de leitura
- [x] **AC3:** **Given** `getSectorDashboardConfig(supabase, tenantId, stageId)`, **When** chamado, **Then** retorna o `layout` salvo do setor **ou** o layout default quando não houver registro (sem crash).
- [x] **AC4:** **Given** o helper, **When** o `layout` salvo tiver shape inválido, **Then** faz fallback seguro (default) sem quebrar — validação defensiva.

### C — API
- [x] **AC5:** **Given** `GET /api/sector-dashboard-config?stage_id=<uuid>`, **When** um usuário autenticado do tenant chama, **Then** retorna o layout (salvo ou default) + metadados.
- [x] **AC6:** **Given** `PUT /api/sector-dashboard-config` com `{ stage_id, layout }` e **role ADMIN**, **When** chamado, **Then** faz **upsert** por `(tenant_id, stage_id)` com `updated_by = user.id`, validando o shape do layout (rejeita inválido com 400).
- [x] **AC7:** **Given** um usuário **não-Admin**, **When** tenta `PUT`, **Then** recebe **403** (GET continua liberado a autenticados; defesa no servidor, não só na UI).
- [x] **AC8:** RLS tenant-scoped respeitada (a tabela já tem policies via `auth_tenant_id()`).

## Notas Técnicas
- **Default layout:** definir uma lista enxuta de widgets cobrindo o que o `computeSectorKpis` (8.35) já entrega: `progress` (meta do momento), `status`/`comparison` (distância diária + períodos), `timer` (tempo de processo), `status` (facção). Posições/sizes coerentes com bento 12-col.
- **Admin gate:** mesmo padrão da 8.33 — `user.app_metadata?.role !== 'ADMIN'` → 403 no PUT.
- **Upsert:** `supabase.from('sector_dashboard_configs').upsert({...}, { onConflict: 'tenant_id,stage_id' })` (índice único já existe).
- **Validação de shape:** checar que `layout` é array e cada item tem `type`/`metric`/`size` válidos; descartar/normalizar itens inválidos.
