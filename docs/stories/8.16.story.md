## Descricao

Como gerente, preciso poder excluir uma OP criada por engano. Decisao do dono: a exclusao e um **cancelamento/arquivamento (soft delete)** — a OP some das listas operacionais mas permanece guardada no historico para auditoria.

**Gap:** `production_orders/[id]` so tem `GET`. Nao ha como cancelar/remover uma OP.

**Solucao:** `DELETE` soft (status `CANCELLED`) + registro em `audit_log` + ocultar canceladas da listagem padrao.

## Criterios de Aceitacao

- [ ] **AC1:** Given usuario com permissao (`orders:create`/admin), When `DELETE /api/production/orders/[id]`, Then OP recebe `status='CANCELLED'` (nao e apagada fisicamente)
- [ ] **AC2:** Given cancelamento, When executado, Then registra em `audit_log` (action=CANCEL_OP, user_id, entity_id, motivo) com `tenant_id`
- [ ] **AC3:** Given listagem `GET /api/production/orders`, When carrega, Then OPs canceladas NAO aparecem por padrao
- [ ] **AC4:** Given `GET /api/production/orders?include_cancelled=true`, When carrega, Then inclui canceladas (auditoria)
- [ ] **AC5:** Given usuario SEM permissao, When tenta cancelar, Then erro 403
- [ ] **AC6:** Given UI no detalhe da OP, When clica "Cancelar OP", Then modal exige confirmacao (digitar numero da OP) + motivo
- [ ] **AC7:** Given OP cancelada, When acessada diretamente, Then exibida como cancelada (somente leitura, sem novas bipagens/lotes)
- [ ] **AC8:** `npm run typecheck` e `npm run lint` passam sem erros
