## Descricao

Como operador de expedicao, preciso de uma pagina de conferencia de carga (Aduana) onde eu escanejo lotes antes do envio e o sistema me mostra visualmente (verde/laranja/vermelho) se cada lote esta na remessa correta, para evitar envios errados.

**Gap:** Schema `AduanaValidation` existe mas nao ha UI nem fluxo operacional.

**Solucao:** Pagina `/aduana` fullscreen com modo de conferencia: selecionar motorista/remessa → escanear lotes → validacao em tempo real com cores + feedback sonoro.

## Criterios de Aceitacao

- [ ] **AC1:** Given operador acessa `/aduana`, When seleciona motorista e remessas, Then modo scan inicia com foco automatico no campo barcode
- [ ] **AC2:** Given lote pertence a remessa selecionada, When escaneado, Then tela fica VERDE + beep curto + "OK — Rota correta"
- [ ] **AC3:** Given lote pertence a outra remessa, When escaneado, Then tela fica LARANJA + beep duplo + "ATENCAO — Lote de outra remessa" + botoes "Prosseguir"/"Separar"
- [ ] **AC4:** Given lote nao existe no sistema, When escaneado, Then tela fica VERMELHO + tom grave + "BLOQUEADO — Lote nao encontrado"
- [ ] **AC5:** Given lote ja foi escaneado nesta sessao, When escaneado novamente, Then tela fica VERMELHO + "Lote ja bipado — possivel duplicacao"
- [ ] **AC6:** Given operador ignora alerta laranja/vermelho e prossegue, When registrado, Then `alertIgnored=true` com userId + timestamp
- [ ] **AC7:** Given conferencia finalizada, When clica "Finalizar", Then modal de resumo com contadores (X verde, Y laranja, Z vermelho) + lista de alertas ignorados
- [ ] **AC8:** Given modo scan ativo, When operador esta na tela, Then layout e FULLSCREEN sem sidebar
- [ ] **AC9:** Cada validacao registrada em `aduana_validations` com alertColor e alertReason
- [ ] **AC10:** `npm run typecheck` e `npm run lint` passam sem erros
