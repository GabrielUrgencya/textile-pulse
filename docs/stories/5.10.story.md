## Descricao

Como equipe, preciso que o LISION esteja deployado em producao na Vercel Pro com todas as variaveis de ambiente configuradas, dominio acessivel, e build passando com sucesso.

## Criterios de Aceitacao

- [ ] **AC1:** Projeto deployado na Vercel com plano Pro ($20/mes)
- [ ] **AC2:** Variaveis de ambiente configuradas: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `SENTRY_DSN`, `SENTRY_AUTH_TOKEN`
- [ ] **AC3:** Build passando sem erros em producao
- [ ] **AC4:** Dominio acessivel: `liserie.lision.app` ou `lision.vercel.app`
- [ ] **AC5:** HTTPS ativo (automatico na Vercel)
- [ ] **AC6:** Vercel Analytics ativo e coletando metricas
- [ ] **AC7:** Sentry recebendo erros de producao
- [ ] **AC8:** Health check `/api/health` respondendo 200 em producao
- [ ] **AC9:** Webhook de deploy configurado (notificacao de sucesso/falha)

## Escopo

**IN:**
- Setup Vercel Pro
- Configuracao de variaveis de ambiente
- Dominio customizado (se disponivel) ou .vercel.app
- Validacao de build em producao
- Smoke test dos endpoints

**OUT:**
- CI/CD pipeline customizado (Vercel faz automaticamente)
- Testes E2E automatizados em producao
- CDN customizado
- Multi-region deploy
