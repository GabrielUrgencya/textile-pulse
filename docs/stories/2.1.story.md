## Descrição

Como gerente de produção, preciso criar Ordens de Produção (OP Mãe) que automaticamente geram sub-lotes, permitindo organizar e rastrear toda a produção por etapa de forma granular.

## Critérios de Aceitação

- [ ] **AC1:** CRUD completo de OP: criar, visualizar, editar status, listar
- [ ] **AC2:** OP Mãe tem: código único (auto-gerado, formato `OP-YYYYMMDD-NNN`), cliente, produto, cor, quantidade total, data prevista
- [ ] **AC3:** Sub-lotes gerados automaticamente ao criar OP (quantidade configurável, ex: OP de 1000 peças → 4 lotes de 250)
- [ ] **AC4:** Cada sub-lote tem: código de barras único (Code128), sequência, quantidade, status (`pendente` → `em_produção` → `concluído` → `retrabalho`)
- [ ] **AC5:** Listagem com filtros: status, data, cliente
- [ ] **AC6:** Somente `admin` e `gerente` podem criar/editar OPs

## Escopo

**IN:**
- Tela de criação de OP com formulário completo
- Geração automática de sub-lotes com divisão configurável
- Geração de códigos de barras únicos por sub-lote
- Listagem com filtros e ordenação
- Tela de detalhes da OP com lista de sub-lotes
- Controle de permissão por perfil

**OUT:**
- Edição de sub-lotes individuais (gerados automaticamente)
- Importação de OPs via planilha (Fase 2)
- Integração com ERP externo
- Histórico de alterações na OP

## Notas Técnicas

- Código da OP: `OP-YYYYMMDD-NNN` (NNN = sequencial do dia)
- Código do sub-lote: `{OP_CODE}-L{SEQ}` (ex: `OP-20260309-001-L01`)
- Código de barras: Code128 (compatível com Zebra GC420t)
- Divisão de lotes: campo `lot_size` no form, sistema calcula quantos lotes gerar
- Status da OP derivado dos sub-lotes: se todos `concluído` → OP `concluída`
- **Design Guidelines:** `docs/ux/FRONTEND-DESIGN-GUIDELINES.md` — SEGUIR OBRIGATORIAMENTE para todos os componentes visuais
- **Componentes compartilhados:** Usar `LisionCard`, `PageHeader`, `StatusBadge`, `MetricBox`, `TopBar` de `src/components/`
