## Descrição

Como desenvolvedor, preciso do projeto Next.js configurado com toda a stack (TypeScript, Tailwind, Prisma, Supabase) para iniciar o desenvolvimento dos módulos da Fase 1.

## Critérios de Aceitação

- [x] **AC1:** Next.js 14 (App Router) + TypeScript + Tailwind rodando em `localhost:3000`
- [x] **AC2:** Prisma configurado e conectado ao Supabase (PostgreSQL)
- [x] **AC3:** Schema completo migrado com as tabelas: `tenants`, `profiles`, `stages`, `production_orders`, `lots`, `scan_events`, `defect_records`, `factions`, `faction_shipments`, `drivers`, `aduana_validations`, `daily_metrics`, `notifications`, `audit_log`, `ops_clock`
- [x] **AC4:** Seed com dados de teste: 1 tenant (Liserie), 1 admin (Fabinho), 1 operador (Rodrigo), 8 stages, 1 OP com 3 sub-lotes
- [x] **AC5:** ESLint + Prettier configurados, `npm run lint` passando, `next build` passando

## Escopo

**IN:**
- Inicialização do projeto Next.js 14 com App Router
- Configuração completa do Prisma com Supabase
- Schema de todas as tabelas da Fase 1
- Seed de dados para desenvolvimento
- Linter e formatter

**OUT:**
- Lógica de negócio
- UI/UX de qualquer módulo
- Deploy

## Dependências

- Nenhuma (é a primeira story)

## Notas Técnicas

- Usar `npx create-next-app@14` com App Router
- Prisma schema deve refletir a arquitetura documentada em `ARCHITECTURE.md`
- Supabase project já deve estar criado antes de iniciar
- Seed deve usar `prisma db seed` com arquivo `prisma/seed.ts`
