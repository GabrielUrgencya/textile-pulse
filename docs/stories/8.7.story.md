## Descricao

Como operador/gerente, preciso ver visualmente em que etapa do ciclo de faccao cada remessa esta (Preparando → Enviado → Com Faccao → Retornando → Devolvido), com cores de urgencia baseadas no prazo, para acompanhar o transito sem precisar abrir cada registro.

**Gap:** Nao ha indicacao visual clara de onde o lote esta no ciclo faccao. Status e texto puro.

**Solucao:** Componente `ShipmentTimeline` com stepper horizontal de 5 estados + cores de urgencia.

## Criterios de Aceitacao

- [ ] **AC1:** Given shipment na pagina de faccoes, When visualizado, Then stepper horizontal mostra 5 estados com estado atual destacado
- [ ] **AC2:** Given estado atual, When prazo > 2 dias, Then cor verde
- [ ] **AC3:** Given estado atual, When prazo 0-2 dias, Then cor laranja
- [ ] **AC4:** Given estado atual, When prazo < 0 (atrasado), Then cor vermelha + circulo pulsa
- [ ] **AC5:** Given portal da faccao (mobile), When visualizado, Then stepper vira vertical (responsivo)
- [ ] **AC6:** Given estados passados, When visualizados, Then circulo preenchido + linha solida
- [ ] **AC7:** Given estados futuros, When visualizados, Then circulo outline + linha tracejada
- [ ] **AC8:** `npm run typecheck` e `npm run lint` passam sem erros
