## Descricao

Como administrador, preciso visualizar e gerenciar os membros da equipe (operadores, coordenadores, gerentes), para controlar quem tem acesso ao sistema e com quais permissoes.

**Contexto:** A pagina `/team` existe como placeholder. A tabela `profiles` ja armazena todos os usuarios com campos: full_name, role (ADMIN, GERENTE, COORDENADOR, OPERADOR), sector, phone, email, is_active. A autenticacao e via Supabase Auth. Esta story substitui o placeholder por uma tela de listagem e gestao.

## Criterios de Aceitacao

- [ ] **AC1:** Tela `/team` lista todos os membros do tenant com nome, email, role, setor, status (ativo/inativo). Acessivel para ADMIN e GERENTE (permission `users:manage`)
- [ ] **AC2:** Filtros: por role, por status (ativo/inativo), busca por nome
- [ ] **AC3:** Acao "Editar Role": modal para alterar role de um membro (dropdown com roles disponiveis). ADMIN pode alterar qualquer role. GERENTE nao pode promover para ADMIN
- [ ] **AC4:** Acao "Desativar/Reativar": toggle `is_active` no profile. Membro desativado nao consegue logar
- [ ] **AC5:** Build e typecheck passam: `tsc --noEmit` + `next build` sem erros

## Escopo

**IN:**
- Substituir placeholder por tela funcional
- API `GET /api/team` para listar membros do tenant
- API `PATCH /api/team/[id]` para editar role e status
- Listagem com filtros (role, status, busca)
- Modal de edicao de role
- Toggle ativar/desativar membro
- Verificacao de permissao `users:manage`

**OUT:**
- Convite de novos usuarios (requer fluxo de Supabase Auth invite — story futura)
- Remocao permanente de usuario
- Gestao de setores
- Historico de alteracoes de role
- Upload de avatar
