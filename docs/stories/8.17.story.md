## Descricao

Como gestor, quero abrir o painel da TV por um botao dentro do sistema, sem precisar de um link separado, porque isso e um diferencial comercial e facilita o uso diario.

**Gap:** A TV existe em `/tv` (modo kiosk com token via `/api/admin/kiosk-tokens`), mas o `AppSidebar` nao tem item de TV — hoje so abre por link/token copiado manualmente.

**Solucao:** Item "TV / Painel" no menu + atalho no header do Dashboard que abre a TV em tela cheia, reaproveitando o fluxo de kiosk-token existente.

## Criterios de Aceitacao

- [ ] **AC1:** Given usuario autenticado com permissao de visualizacao, When ve o `AppSidebar`, Then existe item "TV / Painel"
- [ ] **AC2:** Given clique no item TV, When acionado, Then abre o modo TV (`/tv`) em nova aba/tela cheia
- [ ] **AC3:** Given necessidade de token kiosk, When o botao e acionado, Then usa/gera um token valido do tenant via `/api/admin/kiosk-tokens` (sem o usuario copiar link manualmente)
- [ ] **AC4:** Given usuario SEM permissao para gerar token kiosk, When ve o menu, Then o item TV nao quebra a navegacao (degrada graciosamente — esconde ou desabilita)
- [ ] **AC5:** Given atalho no header do Dashboard, When clicado, Then mesma acao de abrir a TV
- [ ] **AC6:** `npm run typecheck` e `npm run lint` passam sem erros

## Notas Tecnicas

- **Token kiosk:** verificar como `/tv` autentica (token na URL). O botao deve obter um token valido (existente ou recem-gerado) e montar a URL `/tv?token=...`. Confirmar contrato de `/api/admin/kiosk-tokens`.
- **Permissao:** geracao de kiosk-token tipicamente e admin — se o usuario nao tiver, esconder/desabilitar o atalho (AC4).
- **Abrir tela cheia:** `window.open('/tv?token=...', '_blank')`; o layout kiosk ja e fullscreen.
- **REGRA 7:** componentes de TV vivem em `src/components/tv/`; aqui mexemos em layout/dashboard, nao na TV em si.
