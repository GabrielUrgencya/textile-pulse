## Descricao

Como coordenador de expedicao, preciso registrar e acompanhar o tempo de espera dos motoristas (chegada → carga → saida), com timer ao vivo e metricas agregadas, para otimizar o tempo de operacao e reduzir filas.

**Gap:** Tabela `ops_clock` existe no schema sem nenhuma UI ou API.

**Solucao:** Pagina `/expedition` com widget de fila de motoristas (timer ao vivo) + dashboard de metricas.

## Criterios de Aceitacao

- [ ] **AC1:** Given motorista chega, When operador registra chegada, Then timer inicia automaticamente
- [ ] **AC2:** Given motorista na fila, When timer < 30min, Then cor neutra. 30-60min = amber. >60min = red pulsante
- [ ] **AC3:** Given motorista aguardando, When operador clica "Iniciar Carga", Then timer muda cor para azul (working)
- [ ] **AC4:** Given carga finalizada, When operador clica "Finalizar Carga", Then timer para e mostra duracao
- [ ] **AC5:** Given motorista saindo, When operador clica "Registrar Saida", Then card some da fila (vai pro historico)
- [ ] **AC6:** Given metricas, When pagina carrega, Then mostra tempo medio espera, tempo medio carga, total motoristas hoje
- [ ] **AC7:** Given API OpsClock, When chamada sem tenantId, Then query filtrada corretamente (FALHA 5 corrigida)
- [ ] **AC8:** Given permissao, When usuario nao e ADMIN/GERENTE/COORDENADOR, Then acesso bloqueado
- [ ] **AC9:** `npm run typecheck` e `npm run lint` passam sem erros
