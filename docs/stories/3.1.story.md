## Descrição

Como gerente de produção, preciso que os filtros de período do dashboard funcionem corretamente, para visualizar métricas de diferentes períodos (hoje, semana, mês) e tomar decisões baseadas em dados históricos.

**Contexto:** O Dashboard já está extensamente implementado (~1066 linhas em `Dashboard.tsx`) com KPI cards, tabela de OPs, gráfico de lotes por etapa, auto-refresh 30s e layout responsivo. Esta story cobre os gaps restantes: filtros de período não funcionais e performance fix nas APIs.

## Critérios de Aceitação

- [ ] **AC1:** Filtros de período funcionais: botões Hoje/Semana/Mês alteram o `dateRange` passado para as APIs (`?from=YYYY-MM-DD&to=YYYY-MM-DD`). O período selecionado persiste visualmente (botão ativo com destaque)
- [ ] **AC2:** Hook `useDashboardData` aceita parâmetro de período dinâmico e refaz as chamadas quando o período muda (sem esperar o próximo ciclo de polling)
- [ ] **AC3:** APIs `GET /api/dashboard/kpis` e `GET /api/dashboard/production-chart` usam `withAuth()` em vez de `supabase.auth.getUser()` (performance fix — elimina ~200-500ms de network call por request, mesmo padrão aplicado na Story 2.3)
- [ ] **AC4:** Feedback visual: loading state durante troca de período. Toast de erro se API falhar
- [ ] **AC5:** Build e typecheck passam: `tsc --noEmit` + `next build` sem erros

## Escopo

### Filtros de Período — UI

Os botões de período já existem no Dashboard mas são não-funcionais. Identificar o componente que os renderiza e conectar ao estado `selectedPeriod`:

```typescript
type Period = "today" | "week" | "month";
const [period, setPeriod] = useState<Period>("today");

function getDateRange(period: Period): { from: string; to: string } {
  const today = new Date();
  const to = today.toISOString().slice(0, 10);
  switch (period) {
    case "today": return { from: to, to };
    case "week": {
      const d = new Date(today);
      d.setDate(d.getDate() - 7);
      return { from: d.toISOString().slice(0, 10), to };
    }
    case "month": {
      const d = new Date(today);
      d.setDate(d.getDate() - 30);
      return { from: d.toISOString().slice(0, 10), to };
    }
  }
}
```
