## Descricao

Como faccao autenticada no portal, preciso visualizar meu resumo (pecas, prazos, valores), listar lotes enviados para mim, ver devolucoes pendentes, defeitos registrados, extrato financeiro e notificacoes — tudo filtrado exclusivamente pelos meus dados.

## Criterios de Aceitacao

- [x] **AC1:** `GET /api/faction/summary` retorna: total de pecas com a faccao, proximo prazo de devolucao, valor a receber, status geral
- [x] **AC2:** `GET /api/faction/shipments` retorna lotes na faccao (status != RETURNED), com paginacao
- [x] **AC3:** `GET /api/faction/shipments/[id]` retorna detalhes do lote + servico + valor
- [x] **AC4:** `GET /api/faction/returns` retorna devolucoes pendentes ordenadas por urgencia
- [x] **AC5:** `GET /api/faction/defects` retorna defeitos registrados desta faccao
- [x] **AC6:** `GET /api/faction/financial` retorna periodo financeiro aberto + historico
- [x] **AC7:** `GET /api/faction/financial/[period]` retorna detalhes de um periodo
- [x] **AC8:** `GET /api/faction/notifications` retorna notificacoes da faccao
- [x] **AC9:** Todos os endpoints filtram por `faction_id` da sessao (isolamento absoluto)
- [x] **AC10:** Todos os endpoints usam `faction-middleware.ts` para autenticacao

## Escopo

**IN:**
- 8 endpoints GET sob `/api/faction/*`
- Filtragem por faction_id da sessao
- Paginacao nos endpoints de lista

**OUT:**
- Endpoints de escrita/acao (Story 6.5)
- Frontend que consome esses endpoints (Story 6.8)
- Calculo financeiro complexo (usa dados existentes)

## Notas Tecnicas

- **Isolamento:** Toda query deve ter `WHERE faction_id = session.factionId` — NUNCA retornar dados de outra faccao
- **Summary:** Agregar dados de shipments, returns, defects para uma visao rapida (glanceable em 5 seg)
- **Returns ordenacao:** Por urgencia = `expected_return_at ASC` (mais urgente primeiro)
- **Financial:** Periodo = mes/ano, agrupa por `completed_at` dos shipments
- **Notifications:** Filtrar por `faction_id` OU `target_role = 'FACCAO'`
- **Source:** `docs/architecture/FACTION-PORTAL-ARCHITECTURE.md` secao 5.2
