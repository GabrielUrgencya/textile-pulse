## Descricao

Como operador no chao de fabrica olhando para a TV a 3-10 metros de distancia, preciso de um dashboard com design system LISION aplicado corretamente, tipografia escalada para TV (72px hero, 34px KPIs), dados de producao em tempo real (refresh 15s), para acompanhar a operacao sem tocar na tela. Esta story cria o layout kiosk dedicado e reimplementa toda a pagina da TV com os componentes modulares definidos na UX spec.

## Criterios de Aceitacao

- [ ] **AC1:** `src/app/(kiosk)/layout.tsx` criado com viewport meta tags (no zoom, no scroll), dark mode forcado, fontes carregadas
- [ ] **AC2:** Header com logo "LISION", nome do token, turno (shift start-end), relogio atualizado a cada segundo, indicador "AO VIVO" pulsante
- [ ] **AC3:** Ticker de atividade integrado no header (segunda linha h-8) com scroll infinito das ultimas bipagens
- [ ] **AC4:** Hero "Meta do Dia" com LisionCard: numero produzido (72px), meta, barra de progresso h-10 com cor semantica (success >=80%, warning 50-79%, destructive <50%), shimmer overlay, sub-metricas (projecao, ritmo, pico)
- [ ] **AC5:** Grid de 4 KPIs com MetricBox: OPs ativas, lotes ativos, taxa de defeitos, bipagens hoje — com comparacao/meta e trend arrows
- [ ] **AC6:** Pipeline de etapas com barras horizontais proporcionais (maior = gargalo), animacao staggered, shimmer na barra ativa
- [ ] **AC7:** Painel de alertas com severidade visual: critical (vermelho, dot pulsante), warning (amarelo). Empty state positivo quando nao ha alertas
- [ ] **AC8:** Auto-refresh a cada 15 segundos com animacao sutil de flash on change nos KPIs
- [ ] **AC9:** Design system LISION aplicado: LisionCard, bg-card-gradient, border-gradient, shadow-elegant, font-display, font-mono, cores OKLCH semanticas — ZERO cores hardcoded
- [ ] **AC10:** Layout correto em 1920x1080 — sem scroll, sem overflow
- [ ] **AC11:** Todas as animacoes usam Framer Motion (motion v12) com easing padrao `[0.22, 1, 0.36, 1]`
- [ ] **AC12:** `npm run typecheck`, `npm run lint` e `npm run build` passam
