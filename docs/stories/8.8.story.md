## Descricao

Como gerente, preciso ser alertado automaticamente quando uma faccao nao confirma recebimento de uma remessa apos 4 horas do envio, para que eu possa agir e cobrar a confirmacao.

**Gap:** Faccao pode ignorar confirmacao sem consequencia. Nenhum alerta e gerado.

**Solucao:** Endpoint cron que verifica shipments SENT sem confirmacao ha 4h+ e cria notificacoes.

## Criterios de Aceitacao

- [ ] **AC1:** Given shipment com status SENT e sem factionConfirmedAt ha >4h, When cron executa, Then Notification criada para operador (sentBy) + GERENTE
- [ ] **AC2:** Given shipment ja tem notificacao de alerta nas ultimas 4h, When cron executa, Then NAO duplica
- [ ] **AC3:** Given shipment ja confirmado, When cron executa, Then ignorado
- [ ] **AC4:** Given endpoint cron, When chamado sem header x-cron-secret correto, Then retorna 401
- [ ] **AC5:** Given detalhe do shipment, When nao confirmado ha >4h, Then badge "Aguardando confirmacao" amber pulsante + timer
- [ ] **AC6:** `npm run typecheck` e `npm run lint` passam sem erros

## Notas Tecnicas

- **FALHA CORRIGIDA (Arq 12.1 #6):** Cron endpoint DEVE ser protegido com header `x-cron-secret`. Sem isso, qualquer um pode chamar e gerar spam.
- **REGRA 5 (Arq 12.2):** Deduplicacao de notificacoes (verificar existente nas ultimas 4h)
- **REGRA 4 (Arq 12.2):** Tenant isolation — buscar TODOS os tenants no cron e iterar
- **UX (Arq 11.11):** Notification card WARNING. Badge "Aguardando confirmacao" amber pulsante no detalhe do shipment. Timer "Enviado ha Xh — sem confirmacao".

### Protecao do cron:
```typescript
const cronSecret = request.headers.get('x-cron-secret');
if (cronSecret !== process.env.CRON_SECRET) {
  return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
}
```
