## Descricao

Como administrador, preciso de uma tela de configuracoes para gerenciar tokens de acesso (kiosk e faccoes), visualizar/editar meu perfil, e configurar parametros do tenant, para administrar o sistema sem depender de acesso direto ao banco de dados.

**Contexto:** A pagina `/settings` existe como placeholder (`ModulePlaceholder`). As APIs de gestao de tokens JA EXISTEM (`/api/admin/kiosk-tokens` e `/api/admin/faction-tokens` com CRUD completo). O schema tem `KioskToken` e `FactionToken`. O perfil do usuario esta na tabela `profiles` com campos full_name, role, sector, phone, email. Esta story substitui o placeholder por uma tela funcional organizada em abas.

## Criterios de Aceitacao

- [ ] **AC1:** Tela `/settings` com abas: Perfil, Tokens Kiosk, Tokens Faccao. Acessivel apenas para roles ADMIN e GERENTE (permission `settings:manage`)
- [ ] **AC2:** Aba Perfil: exibe dados do usuario logado (nome, email, role, setor). Permite editar nome e telefone via API. Avatar com iniciais
- [ ] **AC3:** Aba Tokens Kiosk: lista tokens existentes (nome, scope, criado em, status). Botoes criar/revogar token. Usa API existente `GET/POST /api/admin/kiosk-tokens` e `DELETE /api/admin/kiosk-tokens/[id]`
- [ ] **AC4:** Aba Tokens Faccao: lista tokens existentes. Botoes criar/revogar. Usa API existente `GET/POST /api/admin/faction-tokens` e `DELETE /api/admin/faction-tokens/[id]`
- [ ] **AC5:** Build e typecheck passam: `tsc --noEmit` + `next build` sem erros

## Escopo

**IN:**
- Substituir placeholder por tela funcional com abas
- Aba Perfil (visualizacao + edicao basica)
- Aba Tokens Kiosk (CRUD usando APIs existentes)
- Aba Tokens Faccao (CRUD usando APIs existentes)
- Verificacao de permissao `settings:manage`

**OUT:**

- API de update de profile (criar apenas `PATCH /api/profile` simples)
- Gestao de outros usuarios (modulo Team — Story 3.6)
