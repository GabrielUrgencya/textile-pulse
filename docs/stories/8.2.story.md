## Descricao

Como operador de expedicao, preciso que ao enviar um lote para a faccao, o sistema gere um codigo de 6 digitos que a faccao precisa digitar no portal para confirmar recebimento, para que eu tenha prova verificavel de que a faccao recebeu a carga.

**Gap:** Lote sai do barracao mas faccao nao confirma recebimento de forma verificavel. Qualquer um pode clicar "confirmar" sem prova.

**Solucao:** Gerar codigo numerico de 6 digitos ao criar shipment. Faccao digita o codigo no portal via InputOTP para confirmar.

### Codigo de geracao obrigatorio:
```typescript
import { randomInt } from 'crypto';

async function generateUniqueDeliveryCode(tenantId: string): Promise<string> {
  for (let i = 0; i < 3; i++) {
    const code = String(randomInt(100000, 999999));
    const exists = await prisma.factionShipment.findFirst({
      where: { deliveryCode: code, status: { in: ['PREPARING', 'SENT'] } }
    });
    if (!exists) return code;
  }
  throw new Error('Failed to generate unique delivery code');
}
```
