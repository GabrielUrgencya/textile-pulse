## Descricao

Como gerente administrativo, preciso exportar lotes finalizados (em estoque) em formato CSV/Excel para importar no ERP externo, para que a integracao entre sistemas seja possivel sem redigitacao manual.

**Gap:** Zero integracao com ERP externo. Todos os dados ficam isolados no Lision.

**Solucao:** Endpoint GET `/api/export/stock-entries` + modal de exportacao com filtros.

## Criterios de Aceitacao

- [ ] **AC1:** Given GET `/api/export/stock-entries`, When chamado com periodo, Then retorna CSV com: data_entrada, op_number, referencia, lote, quantidade_ok, quantidade_defeito, quantidade_descarte
- [ ] **AC2:** Given periodo > 90 dias, When solicitado, Then retorna erro 400 "Periodo maximo: 90 dias"
- [ ] **AC3:** Given exportacao, When resultado > 5000 registros, Then limitado a 5000 (safety net)
- [ ] **AC4:** Given modal de exportacao, When aberto, Then mostra DatePicker + formato (CSV/Excel) + filtro status + preview contagem
- [ ] **AC5:** Given filtros alterados, When mudados, Then preview atualiza contagem em tempo real
- [ ] **AC6:** Given download, When clicado, Then arquivo baixa direto no browser + toast de sucesso
- [ ] **AC7:** Given permissao, When usuario nao e ADMIN/GERENTE, Then acesso bloqueado
- [ ] **AC8:** `npm run typecheck` e `npm run lint` passam sem erros
