## Descrição

A OP nasce com status `OPEN` e só transita para `COMPLETED` (quando todos os lotes entram no estoque, `scan/route.ts`) ou `CANCELLED`. **Nada nunca a coloca em `IN_PROGRESS`.** Como o card "EM PRODUÇÃO" do painel admin (`orders/page.tsx`) conta `status === "IN_PROGRESS"`, ele fica **sempre vazio** — a OP em produção da Karen "some" da visão da Érica.

## Critérios de Aceitação

- [x] **AC1:** **Given** uma OP `OPEN` com lotes, **When** um lote dela é bipado/avançado (scan registrado), **Then** a OP passa para `IN_PROGRESS` (apenas se estava `OPEN`).
- [x] **AC2:** **Given** a OP em `IN_PROGRESS`, **When** a Érica (admin) abre Ordens de Produção, **Then** a OP aparece no card/contagem "EM PRODUÇÃO".
- [x] **AC3:** **Given** a regra de conclusão (8.19), **When** todos os lotes entram no estoque, **Then** a OP ainda vai para `COMPLETED` normalmente (a transição `OPEN→IN_PROGRESS` não interfere; o update de COMPLETED já cobre `["OPEN","IN_PROGRESS"]`).
- [x] **AC4:** **Given** o painel de OPs aberto, **When** o status de uma OP muda no backend, **Then** a lista atualiza **sem refresh manual** (polling/refetch periódico, ex.: 15–30s).
- [x] **AC5:** **Given** uma OP `CANCELLED`, **When** ocorre um scan tardio, **Then** ela **não** volta para `IN_PROGRESS` (só `OPEN` transita).
- [x] **AC6:** `lint`, `tsc`, `build` passam.

## Escopo

**IN:**
- `src/app/api/scan/route.ts` — após o update de status do lote, setar `production_orders.status = 'IN_PROGRESS'` onde `id = lot.po_id AND status = 'OPEN'`.
- `src/app/(app)/production/orders/page.tsx` — polling/refetch periódico da listagem.

**OUT:**
- Realtime via websockets/Supabase Realtime (polling simples basta).
- Mudança de schema (status já é texto livre).

## Notas Técnicas
- O update de COMPLETED no `scan/route.ts` (~linha 180-186) já filtra `.in("status",["OPEN","IN_PROGRESS"])` — compatível.
- Idempotente: condicionar a transição a `status='OPEN'` evita "ressuscitar" OPs canceladas/concluídas.
- Polling: usar `setInterval` com cleanup no `useEffect` (cuidar para não duplicar com refetch de foco).
