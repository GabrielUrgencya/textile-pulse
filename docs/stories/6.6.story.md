## Descricao

Como sistema, preciso de um job automatico que rode diariamente e verifique contestacoes vencidas (>3 dias uteis sem resolucao pelo gerente), resolvendo-as automaticamente a favor da faccao, zerando a deducao financeira e notificando o gerente.

## Criterios de Aceitacao

- [ ] **AC1:** Edge Function cron configurada para rodar diariamente as 08:00 (horario de Brasilia)
- [ ] **AC2:** Job identifica contestacoes com `faction_response = 'CONTESTED'` AND `contestation_resolved_at IS NULL` AND `faction_response_at` > 3 dias uteis atras
- [ ] **AC3:** Para cada contestacao vencida: zera `deduction_value` no faction_shipment associado
- [ ] **AC4:** Preenche `contestation_resolved_at = now()` no defect_record
- [ ] **AC5:** Cria notificacao CRITICAL para gerente: type=`CONTESTATION_EXPIRED`
- [ ] **AC6:** Usa funcao `addBusinessDays` de `src/lib/business-days.ts` (criada na Story 6.3)
- [ ] **AC7:** Job e idempotente — rodar duas vezes nao causa duplicacao

## Escopo

**IN:**
- Supabase Edge Function com schedule cron
- Query para identificar contestacoes vencidas
- Acoes automaticas: zerar deducao, resolver contestacao, notificar
- Calculo de dias uteis (reusar business-days.ts)

**OUT:**
- Feriados configuraveis por tenant (Fase 2)
- Dashboard de contestacoes vencidas (pode ser adicionado ao admin futuramente)
- Retry automatico em caso de falha parcial (Fase 2)

## Notas Tecnicas

- **Edge Function vs pg_cron:** Decisao arquitetural: Edge Function por ser mais facil de debugar e monitorar via Sentry
- **Timezone:** `America/Sao_Paulo` — 08:00 BRT = 11:00 UTC
- **Cron expression:** `0 11 * * *` (11:00 UTC = 08:00 BRT)
- **Business days:** Para o piloto, exclui sabados e domingos. Funcao `addBusinessDays` ja implementada na Story 6.3.
- **Idempotencia:** A query filtra `contestation_resolved_at IS NULL`, entao rodar duas vezes e seguro
- **Acoes do job por contestacao vencida:**
  1. `UPDATE faction_shipments SET deduction_value = 0 WHERE id = shipment_id`
  2. `UPDATE defect_records SET contestation_resolved_at = now() WHERE id = defect_id`
  3. `INSERT INTO notifications (type='CONTESTATION_EXPIRED', severity='CRITICAL')`
- **RISCO:** Supabase Edge Functions rodam em Deno, nao Node.js. A logica de `business-days.ts` pode precisar ser copiada/adaptada para o runtime Deno (imports ESM, sem require). Verificar compatibilidade durante implementacao.
- **Source:** `docs/architecture/FACTION-PORTAL-ARCHITECTURE.md` secao 4 (R1), 8.3
