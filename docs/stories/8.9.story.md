## Descricao

Como gerente financeiro, preciso que o sistema calcule automaticamente o saldo liquido de cada faccao (bruto - descontos por defeito), para que eu tenha visao clara de quanto pagar sem calculos manuais.

**Gap:** Portal mostra dados financeiros mas nao desconta defeitos automaticamente. Calculo e manual.

**Solucao:** Calcular paymentValue e deductionValue automaticamente ao receber shipment. Portal mostra bruto, descontos e liquido.

## Criterios de Aceitacao

- [ ] **AC1:** Given shipment recebido com pecas defeituosas, When PATCH `/api/shipments/[id]/receive`, Then `paymentValue` e `deductionValue` calculados automaticamente
- [ ] **AC2:** Given calculo, When executado, Then `paymentValue = quantityReturned * pricePerPiece` e `deductionValue = quantityDefective * pricePerPiece`
- [ ] **AC3:** Given GET `/api/faction/financial`, When chamado com periodo, Then retorna bruto, descontos e liquido
- [ ] **AC4:** Given portal financeiro, When faccao acessa, Then ve resumo: Bruto (verde) | Descontos (vermelho) | Liquido (branco bold)
- [ ] **AC5:** Given tabela de shipments no portal, When exibida, Then coluna "Desconto" mostra valor em vermelho
- [ ] **AC6:** Given faccao contesta defeito e ganha, When gerente reverte, Then deduction revertido e historico mantido em metadata
- [ ] **AC7:** `npm run typecheck` e `npm run lint` passam sem erros

### Logica de calculo:
```typescript
const paymentValue = quantityReturned * faction.pricePerPiece;
const deductionValue = quantityDefective * faction.pricePerPiece;
const netPayment = paymentValue - deductionValue;
```

### Regras:
- Desconto so aplicado quando gerente confirma defeito
- Se faccao contesta e ganha → reverter deduction
- Historico em `metadata` JSON: `{ adjustments: [{ date, type, amount, reason }] }`
