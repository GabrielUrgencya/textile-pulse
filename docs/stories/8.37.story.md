## Descrição

Evoluir o **Dashboard individual** do colaborador. Hoje (8.21) já existe o `MyMetaCard` com meta **diária** (barra + percent) e há seção "Tempo de processo". Esta story **acrescenta**: metas **semanal/mensal** como indicadores secundários, **tempo de processo do colaborador no dia**, e o estado **"Meta Concluída"** com destaque quando o colaborador bate a meta. O **setor é determinado automaticamente pelo login** (já via `computeUserMeta`) — sem seleção manual.

## Critérios de Aceitação

- [x] **AC1:** **Given** o colaborador logado, **When** o dashboard carrega, **Then** o setor é resolvido **automaticamente** (user_targets → fallback `profiles.sector`), sem seleção manual (comportamento atual da 8.21 — garantir/validar).
- [x] **AC2:** **Given** a meta diária, **When** exibida, **Then** mostra **progresso em tempo real** com indicador visual claro (barra + contador) — evoluir o `MyMetaCard` existente.
- [x] **AC3:** **Given** metas de período, **When** exibidas, **Then** mostra **semanal** e **mensal** como **indicadores secundários** (progresso vs meta do período); usar `sector_targets.weekly_target/monthly_target` (e override do usuário quando houver), derivando da diária quando NULL (marcado como estimado).
- [x] **AC4:** **Given** as bipagens do colaborador hoje, **When** exibido, **Then** mostra o **tempo de processo do dia** do colaborador (tempo decorrido desde a 1ª bipagem; e/ou tempo médio por lote do dia).
- [x] **AC5:** **Given** o colaborador **bateu** a meta diária, **When** o dashboard renderiza, **Then** exibe um estado **"Meta Concluída"** com destaque visual (cor + ícone + mensagem de parabéns), consistente com `daily_achievements` (scope USER) — sem depender da TV.
- [x] **AC6:** **Given** o colaborador **não** bateu, **When** renderiza, **Then** mostra o progresso normal (sem o estado de conclusão).
- [x] **AC7:** `lint`, `tsc`, `build` passam.

## Notas Técnicas
- **Períodos:** progresso semanal/mensal do usuário = soma das bipagens STAGE_IN (ponderadas) na etapa, no intervalo da semana/mês (fuso `America/Sao_Paulo`). Metas: `weekly_target/monthly_target` do setor; se NULL, derivar da diária × dias úteis (estimado).
- **"Meta Concluída":** considerar concluída quando `progress ≥ target` (target > 0). Para consistência multi-dispositivo, pode-se cruzar com `daily_achievements` (scope USER do dia); mínimo aceitável é derivar do próprio `my_meta`.
- **Cadastro das metas de período (admin):** se a Karen precisar definir semanal/mensal por setor, a tela de Metas precisa dos campos `weekly_target/monthly_target` (a coluna já existe). Avaliar incluir aqui ou sinalizar como follow-up — **não** bloquear esta story (derivação cobre o caso sem cadastro).
- **Reuso:** não recriar o `MyMetaCard`; estender. A seção "Tempo de processo" do Dashboard já existe — para o **colaborador**, escopar ao próprio usuário no dia.
