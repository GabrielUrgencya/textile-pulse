## Descricao

Como faccao, quero instalar o portal como app no celular (PWA) para acesso rapido sem precisar abrir o navegador e digitar URL, com icone na tela inicial e experiencia standalone.

## Criterios de Aceitacao

- [ ] **AC1:** `public/manifest.json` criado com name, short_name, display=standalone, start_url=/portal, theme_color, background_color
- [ ] **AC2:** Meta tags PWA adicionadas no layout do portal (manifest link, theme-color, viewport)
- [ ] **AC3:** Icones PWA gerados (192x192, 512x512) com identidade visual LISION
- [ ] **AC4:** Service worker basico para cache de assets estaticos (opcional, pode usar next-pwa)
- [ ] **AC5:** Banner de instalacao customizado aparece apos 2a visita (usando beforeinstallprompt)
- [ ] **AC6:** Portal abre em modo standalone quando instalado (sem barra de navegacao do browser)

## Escopo

**IN:**
- manifest.json com configuracoes PWA
- Meta tags no layout
- Icones PWA
- Banner de instalacao (install prompt)

**OUT:**
- Notificacoes push nativas (Fase 3)
- Sync offline de dados (Fase 3)
- App nativa (React Native, etc.)

## Notas Tecnicas

- **manifest.json:**
  ```json
  {
    "name": "LISION Portal",
    "short_name": "LISION",
    "display": "standalone",
    "start_url": "/portal",
    "theme_color": "#0d0d0d",
    "background_color": "#0d0d0d"
  }
  ```
- **Icones:** Gerar a partir do logo LISION em formato PNG
- **Install prompt:** Interceptar evento `beforeinstallprompt`, mostrar banner customizado apos 2a visita (usar localStorage para contar)
- **Source:** `docs/architecture/FACTION-PORTAL-ARCHITECTURE.md` secao 7.4
