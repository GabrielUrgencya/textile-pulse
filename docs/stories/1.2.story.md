## Descrição

Como administrador da fábrica, preciso controlar quem acessa o sistema com perfis hierárquicos (admin, gerente, operador) e login por PIN rápido para o chão de fábrica, garantindo segurança sem atrapalhar a operação.

## Critérios de Aceitação

- [ ] **AC1:** Login por email/senha para admin e gerentes
- [ ] **AC2:** Login por PIN (4-6 dígitos) para operadores no chão de fábrica
- [ ] **AC3:** 3 perfis implementados: `admin` (tudo), `gerente` (leitura + criação OP), `operador` (apenas bipagem + visualização)
- [ ] **AC4:** Middleware de rota protege todas as páginas — redirect para `/login` se não autenticado
- [ ] **AC5:** Sessão persiste por 8h (turno de fábrica), depois exige re-autenticação
- [ ] **AC6:** Tela de login responsiva funciona em tablet e desktop

## Escopo

**IN:**
- Autenticação email/senha (Supabase Auth)
- Autenticação por PIN (custom, tabela `users`)
- 3 perfis com permissões definidas
- Middleware de proteção de rotas
- Tela de login dual (email ou PIN)
- Gerenciamento de sessão com expiração

**OUT:**
- Recuperação de senha
- OAuth/SSO
- Cadastro self-service (admin cria usuários)
- Audit log de login (Fase 2)

## Notas Técnicas

- PIN é armazenado como hash (bcrypt) na tabela `users`
- Middleware Next.js (`middleware.ts`) na raiz do projeto
- Perfil do usuário vem do campo `role` na tabela `users`
- Sessão via cookie httpOnly com JWT
- PIN mode: tela simplificada com teclado numérico grande (touch-friendly)
