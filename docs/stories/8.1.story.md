## Descricao

Como gerente de producao, preciso que o dashboard calcule a producao usando o coeficiente de referencia (`meta_coefficient`) de cada OP, para que referencias mais complexas tenham peso maior no calculo de meta e eu possa comparar producao de forma justa entre referencias diferentes.

**Gap:** Dashboard usa quantidade absoluta de pecas, sem ponderar por `meta_coefficient`. Uma referencia complexa (coef 1.5) vale o mesmo que uma simples (coef 0.8).

**Solucao:** Modificar queries de KPI para calcular `pecas_produzidas x meta_coefficient`. Adicionar toggle em settings para habilitar/desabilitar.

## Criterios de Aceitacao

## Notas Tecnicas

- **FALHA CORRIGIDA (Arq 12.1 #3):** `meta_coefficient` pode ser NULL ou 0 em OPs antigas. SEMPRE usar `COALESCE(meta_coefficient, 1.0)` ou `Number(order.metaCoefficient) || 1.0`
- **REGRA 6 (Arq 12.2):** Prisma retorna Decimal como `Prisma.Decimal`, nao `number`. Converter com `Number()` + fallback
- **REGRA 4 (Arq 12.2):** Toda query DEVE incluir tenantId no WHERE
- **Logica SQL:**
  ```sql
  -- Antes: COUNT(scan_events) WHERE event_type = 'STAGE_IN'
  -- Depois: SUM(lots.quantity * COALESCE(production_orders.meta_coefficient, 1.0))
  ```
- **Config:** Tenant settings JSON: `"use_weighted_meta": true`
- **UX (Arq 11.4):** Label "Pontos de Meta", tooltip com breakdown, formato 1 casa decimal (ex: "487.5 / 600 pontos")
