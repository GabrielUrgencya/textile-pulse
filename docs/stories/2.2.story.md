## Descrição

Como operador no chão de fábrica, preciso bipar o código de barras do lote com o leitor USB (Tomate) para registrar a passagem dele em cada etapa da produção, com feedback imediato visual e sonoro.

## Critérios de Aceitação

- [ ] **AC1:** Tela de bipagem com campo de input auto-focus que recebe leitura do scanner USB (simula teclado HID)
- [ ] **AC2:** Ao bipar, sistema registra: `lot_id`, `stage`, `operator_id`, `timestamp`, `station`
- [ ] **AC3:** Feedback visual imediato: verde (sucesso), amarelo (lote já bipado nesta etapa), vermelho (lote não encontrado)
- [ ] **AC4:** Feedback sonoro: beep sucesso vs beep erro (Web Audio API)
- [ ] **AC5:** Etapas configuráveis: `corte` → `costura` → `acabamento` → `embalagem` → `expedição`
- [ ] **AC6:** Tela funciona em modo fullscreen para quiosque (botão F11 ou API Fullscreen)
- [ ] **AC7:** Latência máxima de 500ms entre bipagem e feedback

## Escopo

**IN:**
- Tela de bipagem dedicada (`/scan`)
- Input que captura leitura do scanner USB HID
- Registro de evento de bipagem na tabela `scan_events`
- Seleção de etapa atual (operador escolhe onde está)
- Feedback visual com cores e animação
- Feedback sonoro com Web Audio API
- Modo fullscreen

**OUT:**
- Bipagem por câmera/celular (Fase 2)
- Bipagem em lote (múltiplos de uma vez)
- Configuração de etapas pelo admin (hardcoded na Fase 1)
- Offline mode

## Notas Técnicas

- Scanner USB HID envia caracteres + Enter — tratar como input de texto com submit no Enter
- Input deve ter `autoFocus` e re-focus automático após cada bipagem (nunca perder foco)
- Debounce de 300ms para evitar dupla-bipagem acidental
- Etapas são enum no Prisma: `CORTE`, `COSTURA`, `ACABAMENTO`, `EMBALAGEM`, `EXPEDICAO`
- Estação (`station`) pode ser identificada por query param ou config local (ex: `/scan?station=mesa-1`)
- Sons: usar arquivos `.mp3` curtos ou gerar via Web Audio API (oscilador)
