## Descrição

Criar a **biblioteca de primitives visuais** reutilizada pela TV (8.40) e pelo módulo Dashboard (8.42). Componentes de dados consistentes: card glass, bento grid, area chart, barra de progresso, contador animado, estados (loading/empty/error) e helpers de motion. **Nenhuma cor nova** — usar exclusivamente os tokens oklch existentes (`--foreground`, `--muted-foreground`, `--success`, `--warning`, `--destructive`, `--card`, `--border`, `--surface`); glassmorphism via **white-alpha** sobre o dark base.

## Critérios de Aceitação

- [x] **AC1 (KpiCard):** **Given** o `KpiCard`, **When** renderizado, **Then** tem fundo glass (white-alpha + `backdrop-filter: blur`), borda sutil, raio 16px; variante `highlight` com glow no topo (linha gradiente via `--foreground`/semântico, **sem cor nova**); hover (apenas `transform`/`box-shadow`/`border-color`).
- [x] **AC2 (Hierarquia tipográfica):** **Given** os slots do card, **When** usados, **Then** seguem a escala: **label** 11–12px uppercase letter-spacing 0.08–0.1em muted · **valor** 48–56px font-weight 700–800 foreground · **delta** 13px com ícone ↑↓ (success/destructive) · **supporting** 12–13px muted.
- [x] **AC3 (BentoGrid):** **Given** o `BentoGrid` (12 colunas, gap 16px), **When** recebe filhos com `size`, **Then** mapeia `sm`(3col×2row) / `md`(4×3) / `lg`(6×4) / `xl`(12×6) em `grid-column/row span`. Responsivo: colapsa colunas em telas estreitas (módulo Dashboard); a TV usa 12-col fixo sem scroll.
- [x] **AC4 (AreaChartCard):** **Given** dados de série, **When** renderiza (recharts), **Then** área com **gradiente vertical** (cor do token → transparent), **sem grid vertical**, grid horizontal `opacity ~0.1`, tooltip com glass; animação de entrada suave.
- [x] **AC5 (ProgressBar):** **Given** `value`/`max`, **When** renderiza, **Then** track + fill arredondados, transição `cubic-bezier` no width, cor do fill por threshold (neutro/warning/destructive).
- [x] **AC6 (CountUp):** **Given** um valor numérico que muda, **When** atualiza, **Then** o número **anima** suavemente (sobe/desce), nunca pisca; respeita `prefers-reduced-motion`.
- [x] **AC7 (Estados):** **Given** um card, **When** loading/empty/error, **Then** há `Skeleton` (shimmer animado), `EmptyState` (ícone + copy + CTA opcional) e `ErrorState` (mensagem + retry).
- [x] **AC8 (Motion):** **Given** uma grade de cards, **When** monta, **Then** há `card-enter` (fade + translateY + scale) com **stagger 50ms**; animações usam **apenas** `transform`/`opacity` (60fps); respeita `prefers-reduced-motion`.
- [x] **AC9 (Showcase):** **Given** os primitives, **When** entregues, **Then** há uma rota interna de showcase (ex.: `/dev/ui-kit`, admin/dev-only) **ou** aplicação direta documentada na File List, para validação visual.
- [x] **AC10:** `lint`, `tsc` passam; tokens existentes apenas (nenhuma cor nova introduzida).

## Notas Técnicas
- **Glass sem cor nova:** `background: color-mix(in oklch, var(--foreground) 4%, transparent)` ou `rgba(255,255,255,0.04)` + `backdrop-filter: blur(12px)` + `border: 1px solid color-mix(... --foreground 8%, transparent)`. Validar contraste no dark.
- **CountUp:** usar `useMotionValue`+`animate` do `motion` (já instalado) ou `requestAnimationFrame`; sem libs novas.
- **AreaChartCard:** recharts `<AreaChart>` + `<defs><linearGradient>`; `CartesianGrid vertical={false}` e `strokeOpacity` baixo.
- **prefers-reduced-motion:** desativar stagger/countUp quando setado.
- **TV vs app:** o BentoGrid deve permitir modo "fixo 12-col sem scroll" (TV) e "responsivo" (Dashboard) via prop.
