## Descrição

Como gerente, preciso de uma tela simplificada para exibir em TV no chão de fábrica, mostrando o progresso da produção do dia com fontes grandes e alto contraste, sem necessidade de interação.

## Critérios de Aceitação

- [ ] **AC1:** Rota `/tv` acessível sem login (protegida por token simples na URL, ex: `/tv?token=xxx`)
- [ ] **AC2:** Layout otimizado para TV 1920x1080: fontes grandes, alto contraste, sem scroll horizontal
- [ ] **AC3:** Exibe: OPs do dia com progresso por etapa (barras coloridas), alertas de atraso (lotes parados > 2h)
- [ ] **AC4:** Auto-refresh a cada 15s
- [ ] **AC5:** Auto-scroll vertical suave se houver muitas OPs (CSS animation)
- [ ] **AC6:** Modo escuro padrão para reduzir fadiga visual na fábrica

## Escopo

**IN:**
- Página `/tv` com layout TV-first
- Autenticação por token na URL (simples)
- Visualização de OPs do dia com progresso
- Alerta visual para lotes parados (> 2h sem bipagem)
- Auto-refresh 15s
- Auto-scroll suave
- Dark mode fixo

**OUT:**
- Interação touch/mouse na TV
- Configuração de quais OPs mostrar
- Múltiplas TVs com views diferentes
- Som/alarme na TV

## Notas Técnicas

- Token da TV: gerar um token fixo por instalação, salvar na tabela `tv_tokens` ou env var
- Layout: CSS Grid com `font-size` mínimo de 24px para legibilidade à distância
- Cores das barras: `corte`=azul, `costura`=amarelo, `acabamento`=laranja, `embalagem`=verde, `expedição`=roxo
- Alerta de atraso: calcular `NOW() - last_scan_at > 2h` para lotes `em_produção`
- Auto-scroll: CSS `@keyframes` com scroll suave de cima para baixo, pausa no topo e no final
- Considerar usar `<meta http-equiv="refresh">` como fallback de auto-refresh
