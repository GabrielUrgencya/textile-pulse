## Descricao

Como administrador, preciso gerar tokens de kiosk para que TVs na fabrica exibam o dashboard de producao sem necessidade de login interativo, com seguranca por token UUID revogavel vinculado ao tenant.

## Criterios de Aceitacao

- [ ] **AC1:** Tabela `kiosk_tokens` criada: `{id, tenant_id, token (UUID), name, scope, is_active, created_at}`
- [ ] **AC2:** Endpoint `POST /api/admin/kiosk-tokens` cria token (somente ADMIN)
- [ ] **AC3:** Endpoint `GET /api/admin/kiosk-tokens` lista tokens do tenant (somente ADMIN)
- [ ] **AC4:** Endpoint `DELETE /api/admin/kiosk-tokens/:id` revoga token (somente ADMIN)
- [ ] **AC5:** Middleware de kiosk valida token da URL `?token=<uuid>`, extrai tenant_id, cria sessao read-only
- [ ] **AC6:** URL do kiosk: `liserie.lision.app/tv?token=<uuid>`
- [ ] **AC7:** Token sem expiracao automatica, mas revogavel via endpoint
- [ ] **AC8:** RLS em `kiosk_tokens` restrita ao tenant do admin
- [ ] **AC9:** Sessao kiosk permite apenas leitura de dados do dashboard (read-only)

## Escopo

## Notas Tecnicas

- **Item 8 (v2.1):** TV Dashboard sem autenticacao e um risco CRITICO. Solucao: token UUID por tenant.
- **Tabela kiosk_tokens:**
  ```sql
  CREATE TABLE kiosk_tokens (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    tenant_id UUID NOT NULL REFERENCES tenants(id),
    token UUID NOT NULL DEFAULT gen_random_uuid() UNIQUE,
    name TEXT NOT NULL,
    scope TEXT NOT NULL DEFAULT 'dashboard',
    is_active BOOLEAN NOT NULL DEFAULT true,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now()
  );
  ```
- **Middleware:** Verificar `?token=` na URL, buscar em kiosk_tokens, verificar is_active, extrair tenant_id.
- **Sessao read-only:** O kiosk token nao cria sessao Supabase Auth — apenas fornece tenant_id para queries de dashboard.
- **Source:** `docs/architecture/ARCHITECTURE-REVIEW-v2.1.md` item 8
