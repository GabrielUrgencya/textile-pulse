## Descricao

Como operador no chao de fabrica, preciso que a TV mostre os KPIs filtrados pelo turno atual (manha/tarde), com indicador visual de qual turno esta ativo, para que eu saiba exatamente quanto produzimos neste turno especifico.

**Gap:** TV mostra KPIs do dia inteiro sem diferenciar turnos. Operador do turno da tarde ve numeros que incluem o turno da manha.

**Solucao:** Filtro de turno na API kiosk + componente ShiftIndicator na TV.

## Criterios de Aceitacao

- [ ] **AC1:** Given turnos configurados no tenant settings, When TV carrega, Then KPIs filtrados pelo turno atual
- [ ] **AC2:** Given turno da Manha (07:00-12:00), When horario atual e 10:00, Then API filtra scans de 07:00 a 12:00
- [ ] **AC3:** Given horario entre turnos (12:00-13:00), When TV carrega, Then mostra totais do dia inteiro (fallback)
- [ ] **AC4:** Given nenhum turno configurado, When TV carrega, Then mostra totais do dia (backward-compatible)
- [ ] **AC5:** Given ShiftIndicator, When turno da manha, Then badge mostra "[Manha]"
- [ ] **AC6:** Given ShiftIndicator, When turno da tarde, Then badge mostra "[Tarde]"
- [ ] **AC7:** Given KPIs filtrados, When exibidos, Then label ajustado: "Produzido (Manha): X / Y pts"
- [ ] **AC8:** `npm run typecheck` e `npm run lint` passam sem erros

### Configuracao tenant settings:
```json
{
  "shifts": [
    { "name": "Manha", "start": "07:00", "end": "12:00" },
    { "name": "Tarde", "start": "13:00", "end": "18:00" }
  ]
}
```

### Logica de deteccao:
```typescript
function getCurrentShift(shifts: Shift[]): Shift | null {
  const now = format(new Date(), 'HH:mm');
  return shifts.find(s => now >= s.start && now < s.end) || null;
}
// Se null → sem turno ativo → retornar dia inteiro
```
