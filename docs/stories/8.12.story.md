## Descricao

Como operador no chao de fabrica, preciso que a TV mostre os KPIs filtrados pelo turno atual (manha/tarde), com indicador visual de qual turno esta ativo, para que eu saiba exatamente quanto produzimos neste turno especifico.

**Gap:** TV mostra KPIs do dia inteiro sem diferenciar turnos. Operador do turno da tarde ve numeros que incluem o turno da manha.

**Solucao:** Filtro de turno na API kiosk + componente ShiftIndicator na TV.

### Configuracao tenant settings:
```json
{
  "shifts": [
    { "name": "Manha", "start": "07:00", "end": "12:00" },
    { "name": "Tarde", "start": "13:00", "end": "18:00" }
  ]
}
```

### Logica de deteccao:
```typescript
function getCurrentShift(shifts: Shift[]): Shift | null {
  const now = format(new Date(), 'HH:mm');
  return shifts.find(s => now >= s.start && now < s.end) || null;
}
// Se null → sem turno ativo → retornar dia inteiro
```
