## Descrição

Dois ajustes de UX na **Meta diária por processo** (8.21/8.23):

1. **Não dá para limpar/zerar uma meta de processo.** A API `/api/settings/sector-targets` só tem GET/PUT (upsert); não há DELETE. Campo vazio não persiste e ao recarregar o número volta.
2. **Campo "Unidade" aceita número.** Usuário digita "98" e o dashboard mostra "34 98" (dois números grudados). Unidade deveria ser uma palavra (conjuntos, travetadas…).

## Critérios de Aceitação

**A — Limpar meta:**
- [ ] **AC1:** `DELETE /api/settings/sector-targets?stage_id=...` remove a meta do processo (admin only; RLS de delete já existe)
- [ ] **AC2:** No editor (SectorTargetsCard), cada processo COM meta salva mostra um ícone de **lixeira**; clicar remove a meta e persiste vazio
- [ ] **AC3:** Limpar o campo de meta e clicar "Salvar" também remove (DELETE) — não deixa "fantasma"
- [ ] **AC4:** Após remover, recarregar a página mantém o campo vazio (persistiu)

**B — Campo de unidade:**
- [ ] **AC5:** Campo "Unidade" com placeholder claro ("ex: conjuntos") + `datalist` de sugestões (conjuntos, peças, pares, travetadas, cortes, dúzias)
- [ ] **AC6:** Dica curta orientando palavra (não número)
- [ ] **AC7:** No dashboard (`MyMetaCard`), meta e unidade exibidas de forma separada/legível (número forte + unidade em texto suave); se a unidade estiver vazia, mostrar só o número (sem "/ N undefined")

**Geral:**
- [ ] **AC8:** `lint`, `tsc`, `build` passam

## Escopo

**IN:**
- `src/app/api/settings/sector-targets/route.ts` — adicionar `DELETE`
- `src/components/settings/SectorTargetsCard.tsx` — lixeira por linha + clear-on-empty + unidade (placeholder/datalist/dica)
- `src/components/dashboard/Dashboard.tsx` (`MyMetaCard`) — exibição meta/unidade legível

**OUT:**
- Mudança de schema (tabela e policies já existem)
- Unidade como enum fixo (mantém texto livre com sugestões)

## Notas Técnicas

- A policy `sector_targets_delete` já existe (8.21) — só falta o handler na API.
- `MyMetaCard` hoje renderiza `{progress} / {target} {unit}`. Ajustar para não colar números: ex. `{progress} / {target}` + `<span muted>{unit}</span>` (e omitir se vazio).
