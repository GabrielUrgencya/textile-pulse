## Descricao

Como sistema, preciso de um modulo unificado de notificacoes que envie alertas por multiplos canais (interno + e-mail + WhatsApp futuro), uma integracao com Resend para e-mails transacionais, e uma funcao de calculo de dias uteis para prazos de contestacao.

## Notas Tecnicas

- **Resend SDK:** `npm install resend` — SDK oficial para Next.js
- **Env var:** `RESEND_API_KEY` — configurar na Vercel
- **WhatsApp stub:** `src/lib/whatsapp-service.ts` deve exportar mesma interface mas logar `console.warn('WhatsApp integration not configured')` e retornar. Provedor sera **Evolution API** (decisao do owner).
- **Env vars futuras (Fase 2):** `EVOLUTION_API_URL`, `EVOLUTION_API_KEY`
- **Business days:** Para o piloto, apenas sabados/domingos excluidos. Feriados configuraveis na Fase 2.
- **Fallback:** Se e-mail falhar, `Sentry.captureException(error)` e continuar. Notificacao interna SEMPRE deve chegar.
- **Source:** `docs/architecture/FACTION-PORTAL-ARCHITECTURE.md` secoes 4 (R2), 8
