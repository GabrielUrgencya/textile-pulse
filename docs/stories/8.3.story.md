## Descricao

Como gerente de qualidade, preciso que quando um defeito e registrado em um lote que esta com a faccao, o sistema crie automaticamente uma notificacao para essa faccao, para que ela saiba imediatamente que ha um problema de qualidade.

**Gap:** Notificacoes existem no sistema mas nao sao criadas automaticamente quando defeito e registrado. Faccao so descobre o problema quando lote retorna.

**Solucao:** Trigger no endpoint POST `/api/defects` — se lote esta AT_FACTION, criar notificacao automatica.

## Criterios de Aceitacao

- [ ] **AC1:** Given defeito registrado em lote com status AT_FACTION, When POST `/api/defects`, Then Notification criada para a faccao com type='DEFECT_DETECTED'
- [ ] **AC2:** Given defeito com severity GRAVE, When notificacao criada, Then severity = 'CRITICAL'
- [ ] **AC3:** Given defeito com severity nao-GRAVE, When notificacao criada, Then severity = 'WARNING'
- [ ] **AC4:** Given notificacao ja existe para mesmo lote/faccao nas ultimas 4h, When novo defeito, Then NAO duplica notificacao
- [ ] **AC5:** Given lote NAO esta AT_FACTION (ex: em producao), When defeito registrado, Then nenhuma notificacao criada para faccao
- [ ] **AC6:** Given portal da faccao, When faccao entra com notificacao nao lida, Then toast "Novo defeito detectado no Lote X"
- [ ] **AC7:** `npm run typecheck` e `npm run lint` passam sem erros

### Codigo de referencia (Arq Modulo F):
```typescript
// Apos criar DefectRecord com sucesso:
if (lot.status === 'AT_FACTION') {
  const shipment = await prisma.factionShipment.findFirst({
    where: { lotId: lot.id, status: { in: ['SENT', 'RECEIVED_BY_FACTION'] } }
  });
  if (shipment) {
    // Verificar duplicacao
    const existing = await prisma.notification.findFirst({
      where: { tenantId, type: 'DEFECT_DETECTED', factionId: shipment.factionId, readAt: null, createdAt: { gte: subHours(new Date(), 4) } }
    });
    if (!existing) {
      await prisma.notification.create({
        data: {
          tenantId,
          factionId: shipment.factionId,
          type: 'DEFECT_DETECTED',
          title: `Defeito detectado — Lote ${lot.barcode}`,
          message: `${quantity} peca(s) com defeito de ${defectType}. Severidade: ${severity}.`,
          severity: severity === 'GRAVE' ? 'CRITICAL' : 'WARNING',
        }
      });
    }
  }
}
```
