## Descricao

Como gerente de producao, preciso ver um ranking de produtividade dos colaboradores internos (top 5) no dashboard, com pontos ponderados pela meta, para reconhecer os mais produtivos e identificar quem precisa de apoio.

**Gap:** Ranking existe para faccoes mas nao para colaboradores internos.

**Solucao:** Novo endpoint GET `/api/dashboard/team-ranking` + componente `TeamRankingCard` no dashboard.

### Query SQL de referencia:
```sql
SELECT p.full_name, p.sector,
  SUM(se.quantity_scanned * COALESCE(po.meta_coefficient, 1.0)) as pontos,
  COUNT(se.id) as total_scans
FROM scan_events se
  JOIN lots l ON se.lot_id = l.id
  JOIN production_orders po ON l.po_id = po.id
  JOIN profiles p ON se.user_id = p.id
WHERE se.event_type = 'STAGE_IN'
  AND se.scanned_at >= {period_start}
  AND po.tenant_id = {tenantId}
GROUP BY p.id
ORDER BY pontos DESC
LIMIT 5
```
