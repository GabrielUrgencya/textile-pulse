## Descricao

Como gerente de producao, preciso cadastrar cada referencia de produto com o seu coeficiente de meta uma unica vez, para que ao criar uma OP com aquela referencia o sistema preencha o `meta_coefficient` automaticamente, sem digitacao manual repetida.

**Gap:** A tabela `reference_targets` existe no schema (`tenant_id`, `reference`, `meta_coefficient`, `description`) e a API de OP ja aceita `meta_coefficient`, mas (a) nao ha tela/CRUD para cadastrar referencias e (b) o form de Nova OP nao envia `meta_coefficient` nem puxa do cadastro.

**Solucao:** CRUD de referencias usando `reference_targets` + autofill no form de Nova OP.

## Criterios de Aceitacao

- [ ] **AC1:** Given usuario com `settings:manage`, When acessa a aba Referencias em Configuracoes, Then ve a lista de referencias do tenant (reference, coeficiente, descricao)
- [ ] **AC2:** Given formulario de nova referencia, When salva `reference="1006"` e `meta_coefficient=2.0`, Then registro criado em `reference_targets` com `tenant_id` correto
- [ ] **AC3:** Given referencia ja existente para o tenant, When tenta criar duplicada, Then erro 409 (UNIQUE tenant_id+reference)
- [ ] **AC4:** Given form de Nova OP, When usuario digita/seleciona uma referencia cadastrada, Then campo de coeficiente e preenchido automaticamente com o valor cadastrado (editavel)
- [ ] **AC5:** Given referencia NAO cadastrada digitada na OP, When usuario prossegue, Then coeficiente assume `1.0` (fallback) e OP e criada normalmente
- [ ] **AC6:** Given criacao de OP, When submetida, Then o POST envia `meta_coefficient` e a OP persiste o valor correto
- [ ] **AC7:** Given edicao/remocao de referencia, When PATCH/DELETE, Then somente afeta o tenant do usuario (RLS)
- [ ] **AC8:** `npm run typecheck` e `npm run lint` passam sem erros

## Notas Tecnicas

- **REGRA 4 (Arq 12.2):** Toda query inclui `tenant_id` no WHERE; usar `requireTenantId(user)` como em `/api/settings/targets`.
- **Permissao:** `settings:manage` para escrita (padrao de `/api/settings/targets`).
- **UNIQUE:** `reference_targets` tem UNIQUE(tenant_id, reference) — tratar 409.
- **Decimal:** `meta_coefficient` e Decimal — converter com `Number()` + fallback `1.0` (REGRA 6 / FALHA 8.1).
- **Autofill UX:** combo/datalist no campo Referencia do form de Nova OP; ao casar com uma referencia conhecida, setar o state `metaCoefficient`. Manter campo editavel.
- **Padrao API:** seguir estilo de `src/app/api/settings/targets/route.ts` (GET/PATCH com merge).
