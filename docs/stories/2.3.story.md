## Descrição

Como gerente, preciso imprimir etiquetas com código de barras para cada sub-lote, compatíveis com a impressora Zebra GC420t via ZPL, para identificar fisicamente os lotes na fábrica.

## Critérios de Aceitação

- [ ] **AC1:** Botão "Imprimir Etiquetas" na tela de detalhes da OP
- [ ] **AC2:** Gera ZPL válido com: código de barras (Code128), código do lote, nome do produto, cor, quantidade, sequência
- [ ] **AC3:** Opção de imprimir etiqueta individual (1 lote) ou em lote (todos os sub-lotes da OP)
- [ ] **AC4:** Preview da etiqueta na tela antes de imprimir (representação visual do layout ZPL)
- [ ] **AC5:** Envio direto para impressora via `raw` printing (endpoint de impressão local ou rede)
- [ ] **AC6:** Fallback: gerar PDF com etiquetas caso impressora Zebra não esteja acessível

## Escopo

**IN:**
- Geração de comandos ZPL para Zebra GC420t
- Template de etiqueta com código de barras Code128
- Preview visual da etiqueta no browser
- Impressão individual e em lote
- Fallback PDF para impressão genérica
- Registro de impressão na tabela `label_prints`

**OUT:**
- Configuração de template de etiqueta pelo usuário (fixo na Fase 1)
- Suporte a outras impressoras além da Zebra GC420t
- Reimpressão com controle de duplicatas
- QR Code (apenas Code128 na Fase 1)

## Notas Técnicas

- ZPL template fixo, tamanho de etiqueta: 50mm x 25mm (padrão GC420t)
- Code128 é o formato de barras mais compatível com scanners industriais
- Para envio direto: usar `fetch` para endpoint local (ex: `http://localhost:9100`) ou API de bridge
- Alternativa: usar BrowserPrint SDK da Zebra (JavaScript)
- Fallback PDF: usar biblioteca como `jsPDF` ou `@react-pdf/renderer`
- Tabela `label_prints` registra: `lot_id`, `printed_by`, `printed_at`, `method` (zpl/pdf)
