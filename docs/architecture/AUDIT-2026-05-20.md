### 1.3 Hook de Dados — `src/hooks/use-dashboard-data.ts`

O hook `useDashboardData` faz 3 chamadas reais:
- `GET /api/dashboard/kpis` — KPIs reais
- `GET /api/dashboard/production-chart` — Grafico real
- `GET /api/production/orders` — OPs reais

**Problema critico (linha 117):** Quando auth falha (401), o hook seta `kpis: null` silenciosamente e o Dashboard mostra todos os dados mock SEM nenhum indicador visual de que sao falsos.
